Quanah: optional Star Force cascade and a class for hand-entered pieces

- Star Force missions no longer complete the lower levels by default. An item can be tapped straight from 23 to 24, so ticking 24★ now completes only 24★. To bring the old behavior back, tick "Also complete lower star levels" on the Star Force card; it is remembered. Inspector levels, Battlesim floors and boss difficulties still complete the earlier ones.
- Pieces you add by hand now have a Class choice, set to your selected class unless you pick another. You can also change a piece's class when you edit it, which helps with a misread or an older piece with no class saved.
