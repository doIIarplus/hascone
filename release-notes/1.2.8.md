Lighter in the background, faster rescans

- Screen capture and text reading now run only while you scan. They start when a scan begins and close shortly after you finish, so they use no memory or CPU while Hascone sits idle.
- Rescanning gear you've scanned before is much faster: Hascone now remembers text it has already read, even after a restart.
- The first reading of a scan starts sooner, and reading new items is a little faster.
