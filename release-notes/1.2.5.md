Boss tracking, a drop diary and a much smaller data folder

- New Bossing tab. Choose each character's weekly, daily and monthly bosses with difficulty and party size, check off clears, and see this week's crystal income. Only the 14 most valuable weekly crystals per character count, crystals per world are tracked against the 180 limit, and Heroic worlds (Kronos, Hyperion) are valued at five times the Interactive price. Weekly bosses reset every Thursday at 00:00 UTC and Black Mage on the 1st of each month.
- Drop diary. Log notable boss drops (pitched and brilliant items, armor boxes, ring boxes and more) for each character, with item icons and per-item counts.
- Hascone now cleans its data folder on startup. Earlier versions kept a full copy of the scanner runtime for every update, adding about 1 GB each time. The first launch of this version removes those old copies.
- Character Info scans no longer check the character name, so long or hard-to-read names can't make a scan fail.
- The scan window now shows the supported game settings: 2560 x 1440 with Default Ratio (Filter Applied), or 1920 x 1080 or 1366 x 768 with Ideal Ratio, at the default UI scale.
