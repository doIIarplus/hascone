Updates from inside Hascone

- Hascone now checks for new versions when it opens. A small "Update available" pill appears in the bottom-right corner when a download is ready on GitHub. No automatic popups interrupt your work.
- Read the patch notes before downloading, follow download progress, and restart to install when you're ready.
- Your saved characters, scans, snapshots, and settings stay in the same data folder.
- You can also check manually from Settings → Check for updates.

Manage your roster

- Remove characters you no longer track using the trash icon on their home-screen card. A confirmation explains which saved data will be deleted.
- The character selector and sidebar refresh immediately after deletion. Deletion waits until scanning and processing have finished.

Fixes

- Fixed adding characters whose names contain accented letters, such as Bumblë.

If you're using v1.1.2 or earlier, download this version manually once. Future updates can be installed from inside the app.
