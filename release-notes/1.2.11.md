Automatic MapleScouter verification and result navigation

- Calculate now opens a visible, muted MapleScouter window when verification is needed. It closes as soon as the verified session and client configuration are ready; calculations continue without a hidden browser.
- Finished calculations open Scouter's Results tab and select the returned result automatically, including when a saved result is reused or the app view was reloaded.
- Removed the manual cookie input and MapleScouter connection card.
- Added a workaround for a Chromium/WebView2 startup bug that can cause failed Windows sign-ins and account lockouts.
