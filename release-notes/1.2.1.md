Cleaner character cards and a refresh button for character images

- Character cards on the overview now show just the character's name, class, level and Scouter HEXA score.
- The sidebar no longer shows star counts; each row keeps the HEXA score and HEXA fragments.
- A small refresh button at the bottom-left of the character image on the overview, equipment pages and Scouter fetches the latest image from Nexon. It also updates the character's level. If Nexon cannot find the character, for example after a name change, you'll see a message instead.
- Fixed Character Info scans refusing characters with long names. The game cuts long names short (for example "NotFamAny.."), which the scanner read as a different character. It now matches the visible start of the name and also checks the class before accepting it.
